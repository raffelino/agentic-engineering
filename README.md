# Von Vibe Coding zu Agentic Engineering — Errata & Aktualisierungen

Online-Anhang zum Buch **„Von Vibe Coding zu Agentic Engineering — Methoden für professionelle Softwareentwicklung mit KI"** von Thomas Raffelsieper (Carl Hanser Verlag, 2026, ISBN 978-3-446-48854-0).

**➜ Seite: https://raffelino.github.io/agentic-engineering/**

Die Werkzeuglandschaft, die das Buch beschreibt, entwickelt sich schneller, als ein gedrucktes Buch nachziehen kann. Diese Seite hält den Text aktuell: Korrekturen, fortgeschriebene Zahlen und Nachträge — jeweils mit Fundstelle (Kapitel, Abschnitt, Seite) und Quelle, sauber getrennt nach „führt heute in die Irre" und „war zum Redaktionsschluss korrekt".

Diese Seite wird persönlich vom Autor gepflegt und ist kein Angebot des Carl Hanser Verlags.
